# Supporting this project

Digital Legacy Protocol is released as free, open infrastructure — MIT-licensed code, CC0 (public domain) specification, no paywall, no required account, no token. It's built to be adopted without anyone needing to ask permission or pay a fee, on the theory that a protocol people can die relying on shouldn't have a subscription attached.

That said, maintaining it — responding to security reports, reviewing platform adapter contributions, keeping the spec coherent as edge cases surface — takes ongoing time. If this project is useful to you, saved your family friction, or you'd just like to support continued independent research in this space, here's how.

## Non-monetary support

Just as valuable, and free:

- **Star the repo** — helps other people find it when they're searching for this exact problem.
- **Open an issue** if you spot a gap in the spec, especially a real-world scenario it doesn't handle well.
- **Build an adapter** for a platform you use — see [CONTRIBUTING.md](CONTRIBUTING.md).
- **Tell someone** who's dealt with a deceased relative's digital accounts. This project exists because that process is broken for almost everyone; word of mouth from people who've felt that pain is worth more than any donation.

Thank you for considering it either way.
